# RFM-Analysis
RFM Analysis in SQL + Power BI

This SQL project performs an RFM analysis on football jerseys sales data, to segment customers based on their recency of purchase, frequency of purchase, and monetary value of their purchase. Monthly sales data from January 2025 to December 2025 is combined, RFM metrics are created and assigned scores.
The RFM scores are then used segment the customers into different categories e.g. ‘Loyal VIPs’, ‘Potential Loyalists’, ‘Requires Attention’, and ‘At Risk’ customers, all in efforts to retain customers and drive targeted marketing strategies
